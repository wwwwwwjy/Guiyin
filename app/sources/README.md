# 归音下载音源

- builtin.json：随项目保留的原有源目录；Python 实现位于 app/hub_providers.py、netease_provider.py、hub_qq.py、hub_kugou.py。原有网易云 musicjx 备用接口未删除。
- custom.json：随项目分发的自定义 HTTP 音源，初始为空。首次安装时复制到数据卷 sources/custom.json；升级保留数据卷中所有配置，不覆盖。
- 运行时：平台与设置 → 下载音源，可添加、编辑、停用、测试、导入或导出。没有删除按钮。导入采用追加去重，不覆盖已有令牌。
- 导出的 JSON 不含令牌、Cookie 或密码。可将自定义条目放入项目 app/sources/custom.json，随项目分发。不要把私人令牌写入分发文件。
- 可直接导入一个或多个 LX Music `.js` 音源。文件需要 `lx.on(lx.EVENT_NAMES.request, ...)` 和 `lx.send(lx.EVENT_NAMES.inited, {sources: ...})`，目前支持 wy / tx / kg / kw 平台的 musicUrl 操作。MusicFree 的 module.exports 插件不兼容，导入时会明确报错。
- JS 原文件存于数据卷 `sources/scripts/<sha256>.js`，与注册信息一同持久化；重复导入按内容去重，已有启停设置不变。每条 JS 音源可单独下载原文件；JSON 导出只含其目录信息，不含脚本内容。备份/迁移请保存整个 data/sources 目录。
- JS 使用 QuickJS 独立子进程执行，限制内存、CPU、执行时间、请求数与响应大小，不提供 require、文件、环境变量或平台登录凭据。公网请求逐次校验 DNS，固定连接目标 IP，重定向重新检查；不能访问 NAS/局域网。网络接口只开放 HTTP(S) 80/443 端口。
- “已识别”表示脚本接口通过检查。点击“测试”会以选定平台的一首歌进行真实解析和音频头连接测试，结果仅适用于该歌曲与当时网络。导入检查本身不发网络请求。
- JS 常只返回 URL，所请求音质不等于实际音质。下载仍检查实际音频格式和已知完整时长；无可靠时长不能将 JS 结果保存为完整歌曲。

## HTTP 接口约定

填写不含查询串和账号密码的 HTTP(S) URL。接口收到 POST JSON：

```json
{"platform":"qq","id":"歌曲标识","quality":"lossless","title":"曲名","artists":["歌手"],"duration_ms":200000}
```

可选接口令牌通过 Authorization: Bearer 发送，仅发给填写的接口，不跟随重定向。平台登录凭据不会发给自定义接口。
响应顶层（也允许 data 包裹）必须为：

```json
{"platform":"qq","id":"歌曲标识","url":"https://example.com/audio.mp3","preview":false,"duration_ms":200000,"quality":"standard"}
```

quality 为 standard/exhigh/lossless/hires，必须声明实际音质；歌词 lyric 和封面 cover_url 可选。音频 URL 必须为公网 HTTP(S) 地址，沿用现有音频安全检查。
同平台歌曲标识必须完全相同；已知时长偏差不能超过 5 秒。下载后还会校验真实音频格式、声明的无损编码及完整时长。识别格式不等于检测转码，不能保证来源内容真实性。

## 自动切换

每首歌曲按设置中保存的优先级尝试内置、备用、HTTP 和 JS 源。已关联多个平台的歌曲同样按此优先级尝试对应来源。解析、传输或完整性校验失败继续下一个；暂停或取消立即结束，不当作换源失败。不凭模糊歌名替换其他版本。
现有设置中的单个平台网关不迁移删除，会显示为“原有自定义接口”；可停用和恢复。音源测试只读取一首歌的音频头，不向音乐库写文件；通过测试不代表所有歌曲均可下载，也不代表已经通过完整文件校验。

JS 脚本按原始 UTF-8 字节保存和校验，保留 CRLF/LF 换行。相同文件重复导入不会新增音源；文件缺失或损坏时会修复原条目，保留启用状态。

使用优先级：设置中的序号越小越先尝试，自动保存到 custom.json 的 order 数组。内置、原有备用、HTTP 与 JS 源统一排序；仅尝试启用且支持歌曲平台的源。任务中心“开始下载”也会重新安排失败/等待处理任务，运行时使用当前源配置。音源记录显示各次尝试与校验结果，重试会重置旧记录。

## 歌词与封面辅助匹配

按目录补全也使用设置中启用源的相同优先级。先验证平台搜索结果与本地歌曲的歌名、歌手、版本和时长，再向源请求对应歌曲标识。歌词与封面独立回退；已有资源不覆盖，成功来源显示在目录明细中。

LX JS 源需要声明 `lyric` 或 `pic` 动作；只声明 `musicUrl` 的源会跳过。为兼容缓存式脚本，在同一个隔离进程内先调用 `musicUrl` 初始化缓存，再读取 `lyric` / `pic`，不下载返回的音频。保留原有进程与网络限制。

HTTP 自定义源的辅助匹配请求增加 `"action":"assets"`，其余歌曲字段相同；返回相同 `platform`、`id` 以及可用的 `lyric`（LRC 文本）和/或 `cover_url`，允许 `data` 包裹。此操作无需音频 URL、音质或完整音频声明；如提供 `duration_ms`，仍须通过时长校验。不支持此动作或资源失败时继续下一源。
